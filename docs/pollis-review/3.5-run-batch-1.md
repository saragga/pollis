# 3.5 Run the code examples in Julia, batch 1 and pilot

Task 3.5 of the Pollis Polish Roadmap. The code was taken from `node build/pollis/extractCodeExamples.ts` (`.build/code-examples/<id>/<model>.jl`), with every input at its default, and run headless in Julia 1.12.6 (Homebrew build). Each panel gets its own package environment. Each model runs in one Julia process, the way the panel runs in the REPL: the default code first, then every Next Steps action in the same session. The limit is 10 minutes per snippet. API keys are not passed to the snippets. Panels that expect the user's own variables were given small seeded sample data where it had been written (dstats, lm, glm, ht, attr).

The run was stopped after this batch because it is too slow to cover all panels this way (about 1.5 hours for 19 panels). The pilot panels (`dstats`, `lm`, `glm`, `odes`, `ht`) are reported here too. Not run: `autoencoder`, `autotsf`, `azero`, `blv`, `bndt`, `boot`, `bopt`, `cam`, `cca`, `ccdr`, `cds` and every panel after `cds`.

Nothing was fixed here. The fixes belong to task 3.6.

## Bugs for 3.6

### `adlp`
- Predict: Predictions (lr, logr): `dot` is used without `using LinearAlgebra`.

### `alpv`
These calls fail with a `MethodError` before any request is sent, so they are wrong whatever the key:
- Intraday Bars: `time_series_intraday("AAPL", "5min"; interval, outputsize)` has no such method.
- Moving Average: `SMA(symbol; interval, time_period, series_type)` has no such method.
- RSI: `RSI(symbol; interval, time_period, series_type)` has no such method.
- GDP and CPI, and the economic default: `real_gdp(::String; interval)` has no such method.
- Rates and Yields: `treasury_yield(::String, ::String; interval, maturity)` has no such method.

The other calls returned "Empty response received from API" or "Unexpected end of input", which is what the API returns without a key.

### `attr`
- `lorenz!` is called but never defined (all three defaults).
- `basins_fractions_labels` has no method for `BasinMapRecurrences` (attract default, Attractor Plot, Attractor under Param Change, Tipping Point, Recurrence vs Proximity, Single vs Multi-Stability).
- `Random` is used without `using Random` (bifur default, Bifurcation Diagram).
- The recurrence mapper stops with "found via sufficient recurrences, we encountered a cell of a previously-found attractor" (basins default, Basin Fractions, Basin Entropy). The grid or the recurrence settings need tuning.

### `bert`
- Attention Weights and Token Attribution: `nestedcall` has no method for the text decoder in the installed Transformers.jl.
- Compare Models and Top Similar Docs crashed Julia (bus error in the garbage collector while a second model loaded; illegal instruction in LLVM). This may be the Homebrew Julia build rather than the code; rerun them alone to check.
- Similarity Heatmap (similarity) did not finish in 10 minutes; most of the time was spent compiling.

### `glm` (pilot)
- Diagnose: Leverage (all 8 models): `leverage` has no methods in the installed GLM.jl.
- The default code prints `println(coeftable(model))`, which shows the raw `CoefTable(Any[[...` struct. Use `display(coeftable(model))`.
- The Gamma model fits with the canonical inverse link, which fails when the linear predictor goes negative. This is fragile with real data.

### `lm` (pilot)
- wls, Compare: Nested F-Test: `ftest` throws `InexactError: Int64(100.578...)` because non-integer weights give a non-integer residual degrees of freedom.

### `ht` (pilot)
- Default code (parametric, nonparametric): `confint(result, 0.95)` should be `confint(result; level = 0.95)`.
- Compare: Parametric vs Nonparametric (parametric, timeseries): `SignedRankTest(x, 0.0)` does not exist; use `SignedRankTest(x)`.
- The default code prints `println(result)`, which shows the raw test struct (all four models). This came from task 3.4; use `display(result)`.
- multivariate: all 10 actions are "not applicable", so the model has no usable Next Steps; nonparametric has 10 of 10 and timeseries 3 of 10.

## Do the outputs make sense?

The outputs that were checked are plausible:
- `bfmb` classical recovers Market 0.79 (true 0.6) and Value 0.17 (true 0.3), and warns about the useless factor.
- `adlp` lr recovers coefficients 1.01, 2.02, -1.00 (true 1, 2, -1).
- `ande` ae reaches precision and recall of 0.92.
- `blsdf` gives a cross-sectional R2 of 0.97.
- `dstats` gives mean 9.68 and sd 2.15 on data drawn with mean 10 and sd 2.
- `glm` Bernoulli gives 0.43, 0.70, -0.21 (true 0.5, 0.8, -0.4) with n = 200.
- In `ht`, a binomial test of 34 out of 50 gives p = 0.015, and an ADF test on a random walk gives p = 0.43 (no rejection).
