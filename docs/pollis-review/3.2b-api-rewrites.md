# 3.2b: Rewrites of the Panels with Invented Package APIs

Task 3.2 (reports `3.2-semantic-review-batch-*.md`) found 17 panels whose code calls functions their packages do not have. This report covers the rewrites. For each panel, every call was checked against the package source installed locally (package version noted). Running the code is task 3.4.

| Panel | Package and version | Open problems fixed | Models removed |
|---|---|---|---|
| gmm | GMMTools 0.1.0 (unregistered, MIT) | all | none |

## gmm: Generalized Method of Moments

**Invented calls.** `fit(GMM(Heteroscedastic()), df; response, regressors, endogenous, instruments)`, `fit(IV(...), ...)`, `fit(OLS(...), ...)`: Microeconometrics.jl has no `GMM` type and no such keyword interface. Microeconometrics itself cannot be installed today: every version requires DataFrames 0.21 or older (checked in the General registry).

**Real API used.** GMMTools.jl 0.1.0 (Gabriel Kreindler, https://github.com/Gkreindler/GMMTools.jl), read from its source:
- `GMMTools.fit(data, mom_fn, theta0; W = I, mode = :onestep | :twostep, opts = GMMOptions(...))` returns a `GMMFit` with `theta_hat`, `obj_value`, `n_obs`, `n_moms`, `W`.
- `GMMTools.vcov_simple(data, mom_fn, fit)` stores the sandwich covariance in `fit.vcov.V` (moment covariance m'm/n, so heteroskedasticity-robust).
- `GMMTools.boot_weights(data, fit; method = :user, boot_weights_fn, nboot)` and `GMMTools.vcov_bboot(data, mom_fn, theta0, fit, weights; W, run_parallel, opts)` give a Bayesian bootstrap covariance. The built-in `:cluster` method needs a DataFrame, so the panel passes its own cluster weight function (`:user`), which works with any Tables.jl table.
- In the two-step mode the second-step weight is inv(m'm/n) at the first-step estimate, so Hansen's J is `n_obs * obj_value`.

GMMTools is not in the General registry; it was added to `UNREGISTERED_PACKAGE_URLS` in `model.handler.ts`, so the install button uses its URL. It depends on DataFrames and Revise (installed, never used by the panel code) and declares no version bounds, so a future dependency release could break it. It holds FixedEffectModels at 1.13.3 in a shared environment.

**Changes.**
- Moment conditions are written out: `mom_fn(d, theta) = d.Z .* (d.y .- d.X * theta)`, with the constant and the exogenous regressors among the instruments (the old code had no intercept).
- Data: any Tables.jl table, read with `Tables.getcolumn`. With the default name `df`, the code simulates 200 firms over 5 years (log sales on log advertising, which is endogenous through an unobserved demand shock; two advertising-price instruments; firm-clustered, heteroskedastic errors). True coefficients 2.0, 0.5, -0.3, 0.25.
- Input `vcov` (id kept) is relabelled "Estimator": two-step efficient GMM (`het`), one-step GMM with 2SLS weights (`hom`, which was mislabelled as homoscedastic GMM), two-step with cluster bootstrap standard errors (`clustered`). Labels title-cased.
- Actions now reuse the fit from the default code instead of re-fitting six times.
- `first_stage` now computes the partial F of the excluded instruments for every endogenous regressor (batch 4, finding 3).
- `gmm_vs_2sls` no longer promises smaller GMM standard errors; it explains when two-step GMM is more efficient and cites Windmeijer (2005) (batch 4, finding 4).
- `j_statistic` uses the two-step objective, re-estimating two-step GMM when the one-step estimator is selected, and warns that J assumes independent observations in the clustered case.
- New Compare action `ols_vs_gmm`: OLS, GMM and, for the simulated data, the true coefficients.
- Interpret actions explain the effect, the exclusion restriction and what a confidence interval means.
- References added: Windmeijer (2005), Rubin (1981).

**Out of scope.** The four gmm notebooks are "Coming soon!" placeholders, and `media/wiki/gmm/` is empty although the panel lists six wiki pages. No notebook or wiki mentions Microeconometrics.
