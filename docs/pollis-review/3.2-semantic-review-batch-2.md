## Cross-cutting findings

- **Y1. Default code with no data, or data without the feature.** Batch 1's X4 applies here too.
  - Default code reads variables the user must supply in `clbt`, `clf`, `clh`, `clp`, `cmplx`, `chaos` (`rqa`), `cnn`, `com`, `copula`, `covShrinkage`, `ctm`, `ctpf` and `ande`.
  - Two panels do simulate, but their data lacks the feature the method is for:
    - `cest` (Rt): cases are i.i.d. Poisson(20), so there is no epidemic to estimate.
    - `cv`: `y = rand(100)` is unrelated to `X`, so every score is noise.
  - The strong panels (`ctsv`, `dco`, `dcm`, `copt`, `cmp`) build their problem in the code and check the answer against theory or a benchmark.
- **Y2. In-sample numbers described as out-of-sample.** Perplexity is described as held-out in `ctm` and `ctpf` (fixed), but it is computed on the training corpus. Several comparisons also use training fit to pick between models of different sizes: `ctm` and `ctpf` compare topic counts and model types, and `cnn` compares the network against a linear baseline. In-sample fit favours the larger model, so hold out data for these.
- **Y3. Finite-level "tail dependence".** `ceval`, `cps` and `copula` report P(V < q | U < q) at q = 1% or 5% as tail dependence. The tail-dependence coefficient is the limit as q goes to 0: it is 0 for a Gaussian copula, while the finite-level value at 5% and rho = 0.5 is about 0.25. The `copula` description claimed Gaussian copulas give "near 0" at 5% tails and was fixed. The other two should call the quantity "conditional exceedance at q" and mention the limit.
- **Y4. Zygote.** `cnn` trains with `Flux.train!`, which uses Zygote (batch 1, X1).
- **Y5. Actions that ignore the selected model.** In `crn`, the Species Trajectories and Phase Portrait actions always run Lotka-Volterra, and the Steady States and Stoichiometry actions always run Michaelis-Menten, whatever network is selected.

## Panel reviews

### cest: Contagion Models

**Sound: wrong. Worth: adequate.**

1. **Wrong, not fixed. `cest.toml`, model `rt` and every Rt action.** The likelihood `cases[t] ~ Poisson(Rt[t] * cases[t-1])` ignores the generation interval. `Rt` multiplies yesterday's cases, so what it estimates is the day-on-day growth factor, not the reproduction number. The renewal equation (Cori et al. 2013) uses a weighted sum of past incidence, with weights from the serial interval (mean about 5 days for COVID-19). Because the daily growth factor is much closer to 1 than Rt, the panel understates how far Rt is from 1. Proposed fix, in each of the six copies of the model:

   ```julia
   w = diff(cdf.(Gamma(2.5, 2.0), 0:14)); w ./= sum(w)  # discretised serial interval, mean 5 days
   lambda = Rt[t] * sum(w[s] * cases[t - s] for s in 1:min(t - 1, 14))
   cases[t] ~ Poisson(lambda + 1e-6)
   ```

   Not fixed here because it changes the model in six snippets; the author should confirm the serial interval.
2. **Questionable. Model `rt`.** The data are `rand(Poisson(20), T)`, i.i.d. counts with no growth or decline, so Rt stays flat at about 1 and the Rt Trajectory, Forecast and Counterfactual actions show nothing. Proposed fix: simulate a wave from the renewal equation with Rt falling from 2.5 to 0.8 (for example, an intervention on day 40), then show the posterior recovering it.
3. **Wrong, fixed (`a961060a`). Actions `trace-plots` and `forecast`.** A literal `NaN` stood where a number belonged: `Symbol("log_Rt[NaN]")` and `T_fwd = NaN`. They are now the middle day `div(T, 2)` and `T + 14`.
4. **Wrong, not fixed. Action `forecast`.** Even with a horizon, the forecast model has no likelihood beyond day T. The missing future counts are discrete, and NUTS cannot sample discrete variables, so `predict` cannot produce a forecast; the plotting line is a stub (`band!(ax, 1:T_fwd, ...)`). Proposed fix: after fitting, simulate forward from posterior draws. Continue the random walk of `log_Rt` from its day-T value, and draw each day's cases from the renewal equation.
5. **Wrong, not fixed. Action `sir-vs-seir-fit`.** It compares the log posterior of the last MCMC draw of each model. A single draw's log posterior is not a model comparison, and the two models have different parameters and priors. Proposed fix: compare predictive fit to held-out event times, or an information criterion computed from the whole chain.
6. **Wrong, not fixed. Action `transmission-network`.** The "crude R0" is `mean(... .|> x -> 1)`, which is identically 1. An offspring-based estimate is the number of internal transmissions divided by the number of infected individuals, averaged over draws. It needs the Pathogen.jl network fields, so please confirm them in task 3.4.
7. **Minor.**
   - Action `param-posteriors`: the description promises beta, gamma and sigma, but there is no sigma, and the "95% CI" is a credible interval.
   - Action `counterfactual`: it is a single random path; show a band over many.
   - Action `epidemic-curve`: `predict(rt_model(missing, T))` uses `cases[t-1]` inside the likelihood, so it needs the observed series (task 3.4).

### chaos: Chaos Characterisation

**Sound: questionable. Worth: adequate.** Lorenz with the standard parameters; the Lyapunov time, Kaplan-Yorke dimension and correlation dimension are correct.

1. **Wrong, fixed (`1ca5fb6d`). `chaos.toml`, action `noise-sensitivity`.** It added noise and then printed the number of rows: the exponent was never re-estimated. It now estimates the exponent from the clean and the noisy orbit with `lyapunov_from_data`, as the slope of the log divergence. The noise was also 0.01 in absolute units (about 0.1% of the sd), while the comment said 1%; it is now 1% of each variable's sd.
2. **Wrong, fixed (`1ca5fb6d`). Action `surrogate`.** It wrapped embedded data in `CoupledODEs`, but an ODE cannot be built from data. Data and surrogates now use `lyapunov_from_data`, with a Theiler window. 19 surrogates make a one-sided 5% test, and the comments now say so.
3. **Wrong, fixed (`1ca5fb6d`). Action `chaos-classification`.** It classified a negative maximal exponent as "periodic or fixed point" and a near-zero one as "quasiperiodic". For a flow, a limit cycle has a zero maximal exponent: one exponent is always about zero along the orbit. The action now uses the two largest exponents:
   - lambda1 > 0: chaotic;
   - lambda1 about 0 and lambda2 about 0: quasiperiodic (a torus);
   - lambda1 about 0 only: periodic;
   - all exponents negative: stable fixed point.
4. **Wrong, fixed (`1ca5fb6d`). Action `stationarity`.** The description said it compares Lyapunov estimates; the code compares RQA determinism. Model `fracdim`'s comment "integer => non-chaotic" was also wrong: an integer D2 does not rule out chaos.
5. **Questionable.**
   - Model `lyap`: "negative => stable" misses the zero exponent of periodic orbits.
   - Orbits start at (1, 0, 0) without discarding a transient (`Ttr`).
   - Model `rqa`: the recurrence threshold 0.1 is in the units of `x`. Use a fraction of its sd, or a fixed recurrence rate.

### clf: Classification Performance

**Sound: questionable. Worth: thin.**

1. **Questionable. `clf.toml`, action `lift-curve`.** `pos = first(unique(y))` makes whichever label appears first in the data the positive class. If that is not the class the scores refer to, lift falls below 1 and reads as a useless model. 4. **Minor.**

   - "Imbalance below 10% warrants oversampling" is contested advice; with proper scoring rules and threshold choice, resampling is often unnecessary.

**Proposal (thin).** The panel should answer: *which threshold should a credit-default classifier use, and which metric shows it?*

- **Default code.** Simulate 5,000 loans with a 5% default rate and logistic scores of moderate skill.
- **Actions.**

### cmplx: Complexity & Entropy

**Sound: wrong. Worth: adequate.**

1. **Wrong, fixed (`264c66fc`). `cmplx.toml`, model `surr`, actions `multi-surrogate` and `nonlinearity-test`.** The p-value was `mean(null .>= obs)`. Deterministic nonlinear structure makes ordinal patterns more predictable, so the data's permutation entropy is lower than that of its linear surrogates. The test was therefore looking at the wrong tail, and would call a chaotic series "no significant nonlinearity". It now counts `null .<= obs`, with the rank p-value (1 + count) / (1 + n).
2. **Wrong, fixed (`264c66fc`). Model `sampen`.** `r = 0.2` was in the units of the series, while the actions and the tooltip use 0.2 standard deviations. The default is now `0.2 * std(x)`.
3. **Questionable. Input `m`, shared by permutation and sample entropy.** m = 5 suits permutation entropy with N in the thousands. Sample entropy is usually computed with m = 2, because matches of length 6 become rare, and the estimate undefined, unless the series is very long. Proposed fix: a separate input for sample entropy, defaulting to 2.
4. **Questionable. Action `pe-vs-sampen`.** The "agreement" test `abs(pe - sampen / log(5!)) < 0.1` has no basis: the two measures are on different scales and are not expected to coincide. Drop the line.
5. **Questionable. Action `complexity-regime`.** The PE thresholds 0.3 and 0.7 are arbitrary. "High complexity: stochastic or fully chaotic" is misleading, because chaotic series typically have permutation entropy well below white noise's value of 1; that gap is what the surrogate test exploits.
6. **Minor.** Action `entropy-rate`: the description says it extrapolates to large m, but the code only prints SampEn by m. `x` is undefined (Y1).

### cnn: Convolutional Neural Networks

**Sound: questionable. Worth: adequate.** A correct receptive-field formula, a causal TCN with residual blocks, saliency, and first-layer filters.

1. **Questionable. `cnn.toml`, models `conv1d` and `dilated`, action `multi-step`.** Both models end in `GlobalMaxPool`, which takes the maximum over time and discards where in the window each feature fired. The output therefore cannot tell the most recent value from an old one, which is poor for one-step forecasting. Yet Recursive Multi-Step Forecast uses these models as one-step forecasters. The TCN correctly reads the last time step. Proposed fix: use `x -> x[end, :, :]` or `Flux.flatten` before the dense layer for forecasting. `SamePad` is non-causal, which is fine for sequence regression but should be stated.
2. **Questionable. Action `linear-baseline`.** It compares the training MSE of a network with about 37,000 parameters against least squares. In-sample, the network wins by capacity alone. Compare on `X_test`, as the `holdout` action does.
3. **Policy.** Y4 (Zygote). `X`, `y` undefined (Y1).

### copt: Constrained Optimisation

**Sound: sound. Worth: rich.** A convex toy problem: project (1.5, 1) onto the unit disc cut by x2 <= x1, where only the disc binds. It checks the KKT conditions with least-squares multipliers, reads the shadow price as a central-difference slope of the relaxed value, and compares five methods.

1. **Minor. `copt.toml`, action `multi-start`.** The problem is convex, so every start reaches the same solution. Say that this is the expected outcome.
2. **Minor. Action `sensitivity-bounds`.** Shrinking the box by up to 50% gives [-1, 1]^2, which never binds, so every change is 0. Shrink further, to 0.8, or say why nothing moves.

### copula: Copula Estimation

**Sound: questionable. Worth: rich.** Rosenblatt goodness of fit, dependence of the data against the model, a family comparison by AIC, and joint exceedance.

1. **Wrong, fixed (`61e0e4bb`). `copula.toml`, action `tail`.** The description said Gaussian copulas "give near 0" at 5% tails. That holds only in the limit; at 5% tails with rho = 0.5 the conditional probability is about 0.25 (checked by simulation). The description now says so.

### crn: Interaction Network Models

**Sound: questionable. Worth: adequate.**

1. **Wrong, fixed (`fe8752bb`). `crn.toml`, model `genetic` and action `network-domains`.** The repressilator used Hill coefficient 2, production 1 and degradation 0.1. The steady state is P = 2, where each repression step has log-gain 2 x 4 / 5 = 1.6. 2. **Wrong, fixed (`fe8752bb`). Action `network-domains`.** The description promised Lotka-Volterra, the repressilator and SIR compared by oscillation period. The code runs two networks and prints amplitudes; the description now says that.

4. **Questionable. Action `network-summary`.** "0 means well-behaved dynamics": the deficiency-zero theorem also needs weak reversibility. The Lotka-Volterra network printed has deficiency 1.
5. **Questionable.** Y5. Action `ode-vs-gillespie` shows one stochastic path from a single infective. With R0 = 10, about 1 run in 10 dies out early, and the lesson needs many runs to show it.
6. **Minor.** The SIR R0 = 10 is measles-like; state the time unit. Michaelis-Menten steady states form a continuum until the conservation laws are fixed.

### ctsv: Continuous-Time Stochastic Volatility

**Sound: sound. Worth: rich.** A correct Hagan SABR formula, the jump compensator in the Bates drift, a Feller condition check (it fails: 0.16 < 0.25, and the action reports it), a martingale z-test for discretisation bias, and an implied-volatility smile from Monte Carlo.
