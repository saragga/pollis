## Panel reviews

### exp: Expectations

**Sound: sound. Worth: adequate.** Quadrature against Monte Carlo with a standard error, convergence in the number of nodes, and Jensen gaps. The exponential-utility certainty equivalent (-log E[exp(-aX)] / a) and risk premium are correct, as is the stop-loss premium E[max(X - K, 0)].

1. **Questionable. `exp.toml`, default code.** `Normal(0, 1)` with f(x) = x^2 gives E = 1, a number everyone knows. Proposed fix: a log-normal asset price, so that the call payoff, the certainty equivalent and the Jensen gap of a risky asset carry economic meaning.

### fnn: Feedforward Neural Networks

**Sound: wrong. Worth: adequate.**

1. **Wrong, fixed (`eb654833`). `fnn.toml`, action `holdout`.** "Retrain on 80%" continued training the network the default code had already fitted on every sample, validation rows included, so the validation loss could not reveal overfitting. The action now re-initialises the weights (Glorot for matrices, zero for biases) and the optimiser before training on the 80%.
2. **Wrong, fixed (`eb654833`). Input `latent-dim` (models `ae`, `vae`).** The default latent size was 16 for 10 inputs. With no bottleneck, the network can learn the identity and "compresses" nothing. It is now 3, and the tooltip says it must be below the input size.
3. **Questionable. Model `vae`.** The reconstruction term is an MSE averaged over features and batch, while the KL term is summed over the latent dimensions. The KL is therefore weighted about `input_size` times more than a Gaussian likelihood would weight it, which invites posterior collapse. Use the per-sample summed squared error, as `autoencoder` in batch 1 does.
4. **Questionable. Action `classical-baseline`.** It compares training errors (W4).
5. **Policy.** W6.

### fo: First-Order Methods

**Sound: sound. Worth: rich.**
- Rosenbrock, whose Hessian condition number is about 2,500 at the optimum.
- Gradient descent against conjugate gradient, momentum, Nesterov and BFGS.
- Line searches, a gradient check, and textbook rate estimates.

1. **Minor. `fo.toml`, action `iteration-bound`.** The description gives the CG factor as (sqrt(k) - 1) / (sqrt(k) + 1), but the code squares it; squared is right for f - f*. The bounds hold for quadratics near the solution, while most Rosenbrock iterations are spent in the curved valley; say the estimate is local.

### fom: First-Order Methods

**Sound: questionable. Worth: rich.** It uses Enzyme for the gradients (the policy) and covers iterate averaging and learning-rate sensitivity.

1. **Wrong, fixed (`872c3fcd`). `fom.toml`, input `noise`.** The actions are about stochastic optimisation: the noise floor, Polyak-Ruppert averaging and the spread over 5 seeds. With the default noise of 0, the seeds gave identical runs, there was no noise floor, and averaging only lagged. The default is now 1.0; 0 still gives the deterministic methods.
2. **Questionable. Action `compare-rules`.** All eight rules run at `lr = 0.01`, but their step sizes mean different things: SGD scales the gradient, while Adam takes a step of about `lr` per coordinate. Compare each at its best rate, which Learning-Rate Sensitivity provides.
3. **Minor.** AdamW's weight decay of 0.01 moves the minimiser towards 0; say so. The quadratic's condition number of 10 is mild.

### galg: Genetic Algorithms

**Sound: sound. Worth: rich.** A GA (tournament selection, BLX-0.25 crossover, elitism), BRKGA, compact GA (Harik) and MCCGA on Rastrigin. Comparisons with DE and CMA-ES use the same number of evaluations over several seeds, alongside stagnation and population-size studies. No findings of substance. ### gev: Generalized Extreme Value Distribution

**Sound: questionable. Worth: adequate.**

1. **Wrong, fixed (`189daea0`). `gev.toml`, action `tail_behaviour`.** `p_tail = 1 - cdf(d, quantile(d, 0.99))` is 0.01 for any fitted distribution. It now reports the chance that a new block maximum beats the largest one observed, and the return period of that record.
2. **Questionable. Same action.** The tail type is classified by |xi| > 0.05, but with the usual number of blocks the standard error of xi is often 0.1 or more. Use the confidence interval.
3. **Minor.** The `eval` and `sample` models are a tour of pdf, cdf, quantile and rand; `maxima` is undefined.

### glm: Generalized Linear Models

**Sound: questionable. Worth: adequate.**

1. **Wrong, fixed (`f1b4129c`). `glm.toml`, action `coefficients`.** It reported `exp(coef)` as odds or rate ratios for every family. That holds for the default logit link (Bernoulli, Binomial) and log link (Poisson, Geometric). It does not hold for the Gamma (inverse link), inverse Gaussian (inverse square), Normal (identity) or negative binomial (GLM's canonical NegativeBinomialLink) defaults. Guards now report link-scale coefficients for those.
2. **Questionable. Action `overdispersion`.** The Pearson dispersion ratio is meaningless for 0/1 Bernoulli data. For the Gamma, inverse Gaussian and Normal families the dispersion is a free parameter, so "overdispersed: consider NegativeBinomial" is wrong advice there. Restrict the action to Poisson and Binomial counts.
3. **Minor.**
   - `NegativeBinomial()` fixes theta = 1; `negbin` estimates it.
   - The Gamma family's inverse link can predict negative means; a log link is standard practice.
   - The guards key on the model only, so an overridden link is not reflected.

### glmm: Generalized Linear Mixed-Effects Models

**Sound: sound. Worth: rich.**
- A caterpillar plot and DHARMa-style simulated residuals.
- Conditional against population-level predictions, and the AUC in its Mann-Whitney form.
- Laplace against adaptive quadrature, and the latent-scale ICC (pi^2/3, 1, pi^2/6).

1. **Questionable. `glmm.toml`, action `vs-glm`.** The likelihood ratio test of the random-intercept variance tests a parameter on the boundary (variance >= 0), where the chi-square(1) p-value is conservative. The usual reference is 0.5 chi2(0) + 0.5 chi2(1), i.e. halve the p-value.
2. **Minor.** The overdispersion ratio is meaningless for the default Bernoulli family.

### gmm: Generalized Method of Moments (GMM)

**Sound: wrong. Worth: adequate.**

1. **Wrong, fixed (`eb5d1c68`). `gmm.toml`, action `j_statistic`.** The "Hansen J" was n * mean(e)^2 / var(e). With a constant among the instruments, the mean residual is about zero whatever the instruments, so this tests nothing. It is now the overidentification statistic:
   - g = Z'e / n, the sample moments over all instruments (constant, exogenous regressors, excluded instruments);
   - S, the heteroskedasticity-robust covariance of those moments;
   - J = n g' S^-1 g, against chi-square with (instruments - endogenous) degrees of freedom.
2. **Wrong, fixed (`eb5d1c68`). All snippets.** The space-separated variable inputs were pasted into `[:{{exog}}]`, which rendered as `[:x1 x2]`, where `x2` is an undefined variable. The lists are now `Symbol.(split("..."))`.
3. **Questionable. Action `first_stage`.** The description promises the F > 10 relevance check, but no F statistic is computed. Report the partial F of the excluded instruments.
4. **Questionable. Action `gmm_vs_2sls`.** "GMM SEs should be smaller" holds only asymptotically and under heteroskedasticity; in small samples, two-step GMM standard errors are biased down (the Windmeijer correction).
5. **Minor.** Microeconometrics.jl works on DataFrames, against the Tables.jl policy; check in task 3.4.

The MLP comparison then uses training losses, so "how much the graph adds" is measured in-sample and favours the larger model.

### graphppl: Probabilistic Programming with RxInfer.jl

**Sound: questionable. Worth: thin.**

1. **Wrong, fixed (`0cdab79b`). `graphppl.toml`, model `vmp`, action `free-energy`.** "The ELBO should decrease": it is the free energy, minus the ELBO, that decreases.
2. **Wrong, fixed (`0cdab79b`). Model `bp`.** Belief propagation was called "exact for conjugate Gaussian models". An unknown mean together with an unknown variance under a Gamma prior is not conjugate. The comments now also say that `sigma` is used as a variance.
3. **Questionable. Actions `posterior-mean` and `convergence`.** They plot the posterior "per iteration" from a result stored with `KeepLast()`, which holds a single posterior; use `KeepEach()`.
4. **Minor.** The conjugate choice is a Gamma prior on the precision, or an inverse gamma on the variance. `y_data` is undefined.

**Proposal (thin).** The panel should answer: *when is message passing exact, and how much does mean-field VMP understate uncertainty?*

- **Default code.** A normal model with a Normal-Gamma prior (known closed-form posterior) and simulated data.
- **Actions.**
  - Visualise: the exact posterior against BP (conjugate, exact) and VMP (mean field).
  - Diagnose: the free energy by iteration (`KeepEach`).
  - Predict: the posterior predictive for a new observation.
  - Compare: VMP's posterior variance of mu against the exact one, and against NUTS in Turing.

### gt: Game Theory

**Sound: sound. Worth: rich.**

- Equilibria: support and vertex enumeration and Lemke-Howson, checked by deviation gains and iterated dominance with mixed dominators.

1. **Minor.**

### ham: Heterogeneous-Agent Models

**Sound: questionable. Worth: adequate.**

1. **Questionable. `ham.toml`, action `equilibrium_rate`.** In the Huggett economy, bonds are in zero net supply, so equilibrium needs aggregate wealth equal to 0. With borrowing limit `phi = 0` and the grid starting at 0, nobody can borrow: aggregate wealth is positive for every r, and `find_zero` has no interior root. The model needs phi > 0 and a grid from -phi. Not fixed here, because the grid is written out in six snippets and `HuggettModel`'s phi convention should be confirmed in task 3.4.
2. **Questionable. Actions `wealth_gini`, `convergence`, `consumption_insurance`.** `g` is used as probability weights (the Gini, `dot(g, w)`), but its mass is checked as `sum(g)`. If `g` is a density on the grid, the weights are `g * dw`; be consistent.
3. **Questionable. Action `consumption_insurance`.** `sigma / sqrt(2 kappa)` is the standard deviation of the OU income state, not a coefficient of variation, and 1 - CV_c / CV_y is not a standard insurance measure. The Blundell-Pistaferri-Preston pass-through coefficient is.

### hmd: Handle Missing Data

**Sound: sound. Worth: rich.** A missingness map, an MCAR heuristic (correctly labelled as not Little's test), holdout RMSE by method, distribution shift, and the sensitivity of means and standard deviations to the method.

### hns: Neighbourhood Search

**Sound: wrong. Worth: rich.**

1. **Wrong, fixed (`45608155`). `hns.toml`, all six models and action `compare-crs-sa`.** Every search started at the centre of the box, (lb + ub) / 2 = (0, 0), which is the global minimum of the default Rastrigin function. The first local descent found the optimum, and every method looked equally good. The searches now start near a corner, at lb + 0.85 (ub - lb).
2. **Minor.** The default problem is 2-dimensional, where most methods cope; the differences between ALNS, basin hopping, ILS, LNS and SA show in 5 to 10 dimensions.

### hpt: Hyperparameter Tuning

**Sound: wrong. Worth: thin.**

The code therefore read `grid = @load grid pkg=` and `model = bayesian(...)`. 3. **Questionable. Action `best-params`.** The best cross-validated score is reported as the model's performance, but the same folds chose it, so it is optimistic. Hold out a test set, or use nested CV (W4). The comment calls the history a DataFrame.

**Proposal (thin).** The panel should answer: *how much does tuning improve on the defaults, and how much of the improvement is selection noise?*

- **Default code.** A gradient-boosted tree (EvoTrees) on a simulated or public credit-default data set, tuning `max_depth` and `eta`.

  - Diagnose: the best CV score against a held-out test score, showing the optimism.

### ht: Hypothesis Testing

**Sound: sound. Worth: rich.**
- Assumption checks (Jarque-Bera, Levene) and Q-Q plots.
- Parametric against rank-based tests, and a permutation p-value with the +1 correction.
- Effect sizes: Cohen's d, Hedges' g (the small-sample factor is right) and eta-squared.
- Decisions at three significance levels.

1. **Questionable. `ht.toml`, action `power`.** It resamples the observed data and treats the observed effect as the true one: "post-hoc power". That is a monotone function of the p-value and says nothing new. Compute power for a pre-specified effect size instead.
2. **Questionable. Models `multivariate` and `timeseries`.** Every action except Decision stops with `error()`, so these toggles have no Next Steps. Hotelling's T^2 and the ADF test deserve their own, for example ADF with `:trend` and a lag chosen by AIC, next to KPSS as the complementary null.

### idat: Interpolate Data

**Sound: sound. Worth: adequate.** A residual check at the knots, a spacing check, derivatives and integrals (exact for Dierckx), and a roughness measure.

1. **Questionable. `idat.toml`, models `bspline` and `cspline`.** They place `ys` on `range(first(xs), last(xs), length(ys))`, which assumes equally spaced `xs`; with irregular `xs`, every value sits at the wrong x. The comment and the residual check mention it, but Method Comparison then compares methods fitted to different data. The natural business example, a yield curve at maturities 1m, 3m, 6m, 1y, 2y, 5y, 10y and 30y, is exactly the irregular case. Use Dierckx or linear interpolation there, or state the restriction in the model description.
