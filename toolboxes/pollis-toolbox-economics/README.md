# Economics Toolbox

The Pollis Economics Toolbox covers quantitative macroeconomics: business cycle filters, stochastic volatility macroeconomic models, DSGE models, heterogeneous-agent models and continuous-time macro-finance.

Installing it adds the **Economics Toolbox** submenu to the **Toolboxes** menu. Each panel has key points, a decision table, example code you can send to the Julia REPL or a notebook, reference wikis and notebook tutorials.

## Panels

| Panel | What it covers | Powered by |
|---|---|---|
| Business Cycle Filters | Hodrick-Prescott, Hamilton, Beveridge-Nelson, Baxter-King and boosted HP filters | MacroEconometricModels.jl |
| Stochastic Volatility Macroeconomic Models | Basic, leverage and Student-t stochastic volatility models | MacroEconometricModels.jl |
| Dynamic Stochastic General Equilibrium (DSGE) | Model moments, estimation and impulse responses | MacroModelling.jl, Dynare.jl, DSGE.jl, SolveDSGE.jl, StateSpaceEcon.jl |
| Heterogeneous-Agent Models | Huggett and Aiyagari economies | EconPDEs.jl |
| Continuous-Time Macro-Finance | Asset pricing through Hamilton-Jacobi-Bellman equations: habit formation, long-run risk, disaster risk and financial intermediaries | EconPDEs.jl |

## Requirements

Julia. Each panel lists the Julia packages it uses on its Powered by line and offers to install the missing ones.
