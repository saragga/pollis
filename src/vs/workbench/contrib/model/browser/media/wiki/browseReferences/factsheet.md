# Browse References — Factsheet

**Browse References** shows every work in PollisReferences: those Pollis cites, those you saved or added, and your corrections.

| | |
|---|---|
| **Purpose** | Search the whole library, remove a work of yours, undo a correction, show a work in a panel's References |
| **Filter** | Show All, User, Corrected, Built-in |
| **Search** | Words of the title, authors, venue or key |
| **Columns** | Year, Work, Key, Citations, In Panels, Records |
| **Actions** | Remove, Undo Correction, Show in Panel..., Possible Duplicates, Merge... |

## When to Use Browse References
- Checking whether a work is already in PollisReferences, and which panels cite it.
- Finding a work's key, to cite it.
- Removing a work you saved by mistake, or going back on a correction.
- Finding two records of one work, and merging them.

## What Browse References Does Not Do
The Browse References page does not search the indexes for new works: Discover Literature finds them, Import References brings them from your files, and Snowball Search follows their citations. A built-in work cannot be removed, only corrected in a panel's Explore References.
