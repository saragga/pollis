# Import References — Factsheet

**Import References** brings references you already have into the same table and actions as Discover Literature, from a file or from pasted text.

| | |
|---|---|
| **Purpose** | Work with a reference list from elsewhere, such as a paper's bibliography or a reference manager's export |
| **Input** | BibTeX or BibLaTeX, RIS, CSL-JSON, or a list of DOIs; the format is told from the text |
| **Files** | `.bib`, `.ris`, `.json` or `.txt`, one or many |
| **Key choice** | Look Up in OpenAlex and Semantic Scholar, or keep the references just as your file has them |
| **Actions** | The same as Discover Literature's, on the ticked references |

## When to Use Import References
- Adding citation counts and open-access links to a reference list.
- Bringing a bibliography into PollisReferences, or into a panel's References.
- Starting a Snowball Search from the works of a paper you are building on.
- Turning a list of DOIs into BibTeX entries.

## What Import References Does Not Do
The Import References page does not change your file, or save anything until you ask. It does not check whether the citations in a document are correct, and without Look Up nothing is sent to the indexes.
