# System Identification Methods: Output Error

The **OE** tab fits an output-error model, y = [B(q)/F(q)]u + e, which describes the plant without a model of the noise. The panel minimises the simulation error of a state-space model with **nf** states, using `newpem` with `focus = :simulation`.

## The output-error criterion

[Söderström and Stoica (1989)](#ref-SS1989a) define the output-error method by

θ̂ = arg min Σₜ ε²(t, θ),  ε(t, θ) = y(t) − [B(q⁻¹)/A(q⁻¹)] u(t),

the sum of squared differences between the measured output and the output of the model driven by the input alone. The panel writes the denominator as F(q), and the decision table gives the purpose of the tab as an output-error model with no noise model, fitted by minimising the simulation error. [Söderström and Stoica (1989)](#ref-SS1989a) treat the method in a complement to their chapter on prediction error methods.

## Consistency

[Söderström and Stoica (1989)](#ref-SS1989a) analyse the output-error estimate under four assumptions: the true system G⁰ is stable; the true noise filter H⁰ is stable and invertible; the numerator and denominator of G⁰ have no common zeros; and the experiment is open loop, E u(t)e(s) = 0.

Under these assumptions, θ̂ converges to the true parameter vector θ₀ as N → ∞ and is asymptotically normal. The noise e(t) enters the true system through H⁰, and the model fits G alone; the default data, generated by an ARX equation with white e(t), have H⁰ = 1/A.

## The code

```
# The package has no polynomial OE estimator; minimising the simulation error
# (focus = :simulation, noise model 1) is the OE criterion
fitm(d) = first(newpem(d, nf; focus = :simulation, show_trace = false))
```

`newpem` returns the model, the initial state and the optimiser result, and `first` keeps the model. The code comment calls the fit the OE criterion in state-space form, with **nf** poles. **Transfer Function** converts the model to a transfer function in z.

## newpem and the simulation focus

The ControlSystemIdentification.jl documentation describes `newpem` as a new implementation of the prediction-error method, an iterative, gradient-based optimisation problem, with BFGS from Optim.jl and an initial guess from `subspaceid`. By default it enforces stability of the estimate by eigenvalue reflection. The default focus is `:prediction`, which minimises the prediction error; with `focus = :simulation`, the K matrix is zero, and the documentation suggests that focus when the prediction focus produces an unstable model for a stable system or poor simulation performance.

With K = 0, the one-step prediction of the model is its simulation. The descriptions of **Predicted Output** and **k-Step Prediction** state that OE has no noise model, so its prediction equals its simulation.

## Simulation and frequency

The documentation notes that simulation tends to require accurate low-frequency properties, especially for integrating systems. **Fit Percentage** and the validation fit printed by every tab use `simulate`, whose output, the documentation states, is not affected by the noise model and Kalman gain, so every printed fit is a simulation fit.

The criterion of the **OE** tab is that same simulation error, on the estimation data. **Compare Structures** prints the validation fit of the OE model beside those of ARX, ARMAX and N4SID, with the same estimation and validation data.

## Orders and delay

**nf** is the only order of the tab: the number of states of the state-space model, which the code comment equates with the number of poles. **Order Selection** refits the model with nf from 1 to 4 and ranks the orders by validation fit.

The tab has no **nk** input. `newpem` forces the D matrix to zero by default, `zeroD = true`, so the model has no direct term from u(t) to y(t); the default plant also starts with u(t−1). The documentation adds that, as the prediction horizon h of `newpem` approaches infinity, the problem approaches the `focus = :simulation` case.
