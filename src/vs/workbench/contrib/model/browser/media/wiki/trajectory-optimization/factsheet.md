# Trajectory Optimization

Trajectory Optimization (TRAJ) solves the problem of computing optimal state and control trajectories for dynamical systems.

## Problem Statement

Given dynamics and cost function, find trajectory that minimizes cost while satisfying constraints.

## Methods

- Direct: Transcription-based approaches
- Indirect: Successive quadratic approximation
- DDP: Second-order indirect methods
- ALTRO: Constrained trajectory optimization
