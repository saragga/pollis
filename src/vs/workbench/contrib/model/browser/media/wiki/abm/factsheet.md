# Factsheet

**Agent-Based Models** runs three classic models with `Agents.jl`, one per type of space. The tabs are complete examples, and a model of your own means editing the agent, its step function and `initialize` in the code.

## What the Agent-Based Models Panel Does

| Item | Detail |
|---|---|
| Purpose | Simulate individual agents, record aggregate quantities, and study how the outcome depends on rules, parameters and chance |
| Julia stack | `Agents.jl` for the models, `Graphs.jl` for the networks, `Tables.jl` for plain columns, `CairoMakie.jl` and `GraphMakie.jl` for figures |
| Tabs | **Grid Space**, **Continuous Space**, **Graph Space** |
| Input shape | No data: every input is a number or a choice, and the agents are generated by the code |
| Time | **Steps (T)**, with every agent acting once per step in random order |
| Randomness | **Seed** sets the starting state and the generator of the model |

## How the Tabs of the Agent-Based Models Panel Differ

| Tab | Model | Agent state | Neighbours | Quantity recorded |
|---|---|---|---|---|
| **Grid Space** | Schelling segregation | Cell and group | Up to 8 surrounding cells, no wraparound | Same-group neighbour share, share of happy residents |
| **Continuous Space** | Vicsek flocking | Position and unit heading | Within radius 1, periodic box | Polarisation |
| **Graph Space** | SIR epidemic | Node and status | Linked nodes | Shares susceptible, infectious and recovered |

## What the Inputs of the Agent-Based Models Panel Default To

| Tab | Input | Default |
|---|---|---|
| All | **Steps (T)** and **Seed** | 100 and 42 |
| **Grid Space** | **Grid Side**, **Density**, **Threshold** | 20, 0.9, 0.3 |
| **Continuous Space** | **Particles (N)**, **Box Side (L)**, **Noise** | 300, 10.0, 0.2 |
| **Graph Space** | **People (N)**, **Mean Degree (k)**, **Network** | 500, 4, **Erdos-Renyi** |
| **Graph Space** | **Infection Probability (beta)**, **Recovery Probability (gamma)**, **Initial Infectious** | 0.1, 0.1, 5 |

## Which Values the Agent-Based Models Panel Fixes in the Code

Some settings have no input and are edited in the code. **Continuous Space** fixes the interaction radius at 1 and the speed at 0.3, as keywords of `initialize`. **Watts-Strogatz** rewires 10% of its links. **Grid Space** always has two groups of equal size and a grid with hard edges. **Ensemble** always runs 20 replicates, with seeds 1 to 20, and **Reproducibility** uses seeds 1 to 10, so those two spreads do not depend on **Seed**.
