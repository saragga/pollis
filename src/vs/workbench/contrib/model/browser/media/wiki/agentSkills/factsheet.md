# Agent Skills — Factsheet

**Agent Skills** lists the skills of the Pollis Agents plugin, with the tasks that use each, examples of what to ask, and its files.

| | |
|---|---|
| **Purpose** | Read a skill, or run it with a coding agent |
| **Input** | The latest skills, downloaded to `~/.pollis/agents/pollis-agents/skills` when the page opens |
| **Columns** | Skill, Tasks, Example Requests, Files, Size |
| **Actions** | View Skill, Run with My Agent, and the links to the tasks |
| **Runs on** | The Standard tier of Model Tasks and Routing |

## When to Use Agent Skills
- Reading what a skill tells an agent to do, before relying on it.
- Starting a skill that has no task of its own in a menu.
- Finding which task of Pollis uses a skill.
- Finding the words that make an agent use a skill.

## What Agent Skills Does Not Do
The Agent Skills page does not install skills for an agent: the box on the page links to Compose > Coding Agents, which does. A skill's text can be read here but not edited, as the next download replaces the copy.
