# Replications — Factsheet

**Replications**, opened by Browse Replications, lists the notebooks that reproduce published analyses on their public data, each printing every published value beside Julia's.

| | |
|---|---|
| **Purpose** | Open a worked reproduction of a published article |
| **Columns** | Replication, Article, Packages, Datasets, Size, Last Updated |
| **Actions** | Click a name to open your copy; Web Page and Copy BibTeX for the article; Open Updated Version |
| **Your copies** | `~/.pollis/workflows`, made the first time you open each |
| **New content** | Replications arrive between releases, marked New or Updated |

## When to Use Replications
- Seeing how a whole published analysis is done in Julia, from the data to the tables.
- Checking how close a Julia package comes to the published numbers.
- Starting from a real analysis and changing it, as the copy is yours.
- Learning a method by following an article you already know.

## What Replications Does Not Do
A replication covers one article's analysis and does not weigh whether its conclusions hold. The list does not include private or restricted data, as each replication runs on public data. Writing a new method with its tests belongs to Browse Methods.
