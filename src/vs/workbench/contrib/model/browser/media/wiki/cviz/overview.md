# Overview

This webview collects the five **core statistical plots** used at the start of almost every analysis. Each answers a different question about the data.

## Scatter Plot
Two numeric variables, one point per observation. Reveals **relationship**, correlation, clusters, and outliers. See [Scatter Plot](scatter.md).

## Bar Chart
A numeric value per category (a count or an aggregate). Compares magnitudes **across discrete groups**. See [Bar Chart](bar.md).

## Histogram
Bins one numeric variable and counts observations per bin. Reveals the **shape** of a distribution — modality, skew, spread. See [Histogram](histogram.md).

## Box Plot
A five-number summary (min, Q1, median, Q3, max) with outliers. Compact, robust, ideal for **comparing groups**. See [Box Plot](box.md).

## Violin Plot
A box plot's summary plus a mirrored kernel density — shows the **full distribution shape**, including multimodality a box hides. See [Violin Plot](violin.md).

## Why It Matters

Each plot trades detail for clarity differently. Picking the right one — and reading it correctly — is the foundation of honest data analysis.
