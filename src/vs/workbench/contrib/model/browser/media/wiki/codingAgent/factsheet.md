# Coding Agents — Factsheet

**Coding Agents** is the page of Compose where the coding agents on this computer are checked, installed and given the Pollis skills.

| | |
|---|---|
| **Purpose** | See which coding agents are on this computer, install them and install the Pollis skills for them |
| **Agents offered** | Claude Code, Codex and OpenCode, and any other agent added under Other Agents |
| **Columns** | Agent, Command, On This Computer |
| **Actions** | Install Agent, Install Skills or Update, and Remove for an agent of your own |
| **Setting** | `pollis.agents.otherAgents` keeps the Other Agents |
| **Key choice** | Which agent runs the tasks: set in Model Tasks and Routing, not here |

## When to Use Coding Agents
- Checking whether an agent's command is found on this computer before starting a task.
- Installing an agent from its own install page.
- Installing the Pollis skills, or updating them, so that an agent can use them in any folder.
- Adding an agent Pollis does not list, by its name and its command line.

## What Coding Agents Does Not Do
The Coding Agents page does not pick a model or say which task runs on which agent: tiers and tasks belong to Model Tasks and Routing. Reading or running a single skill belongs to Agent Skills, and connecting an agent to outside services belongs to MCP Servers. Pollis does not hold an account or a key for any agent, since each agent signs in on its own.
