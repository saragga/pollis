# Import References — Overview

## The Reference Formats Import References Reads

| Format | Where it usually comes from | What it looks like |
|---|---|---|
| BibTeX or BibLaTeX | LaTeX projects ([Patashnik (1988)](#ref-Pat1988a)) | Entries such as `@article{Key, ...}` |
| RIS | Publishers' sites and reference managers | Lines of two-letter tags, such as `TY  - JOUR` |
| CSL-JSON | Zotero and other tools of the Citation Style Language | A JSON array of items |
| DOIs | Any list | One per line, with or without `https://doi.org/` |

The format is told by the text itself, so files of different formats can be chosen together.

## How to Bring References Into Import References
Paste into the box and press **Import**, or use **Choose Files...** for one or many files. Until then the table below says **None yet: import references above.** After importing, the references are in the same table as Discover Literature's, with the same actions on the ticked ones; so a pasted bibliography can go straight to a Snowball Search or to a panel's References. Those actions are described in the wikis of Discover Literature.
