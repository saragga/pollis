# Overview

When the interesting structure is *connection* or *place*, ordinary plots fall short. This webview offers three views for that structure.

## Network Diagram
Draws a **graph**: nodes (entities) joined by edges (relationships), placed by a layout algorithm so that connected nodes sit near each other. Reveals clusters, hubs, bridges, and paths. See [Network Diagram](network.md).

## Tree Diagram
A network that is a **hierarchy** (or DAG), drawn with a tidy top-down layered layout so parent-child structure is immediately legible — org charts, taxonomies, dependency trees. See [Tree Diagram](tree.md).

## Choropleth
A **map** in which geographic regions are shaded by a value using a colour scale — election results, population density, regional sales. See [Choropleth](choropleth.md).

## Why It Matters
Relationships and geography are everywhere — social networks, supply chains, organisational structure, regional statistics. Encoding them as position-and-link or colour-on-a-map communicates structure that no table or bar chart can.
