# Panel Documentation — Factsheet

**Panel Documentation** lists the wikis of every panel, and of the Compose pages that have them, grouped by the menu that opens each.

| | |
|---|---|
| **Purpose** | Find and read a wiki without opening its panel |
| **Columns** | Panel, Wikis |
| **Search** | Search panels and wikis, by their names |
| **Switch** | Written or Not Written, with the count of wikis written |
| **Action** | Click a wiki to read it |

## When to Use Panel Documentation
- Finding which panel covers a topic, when the menu does not make it clear.
- Reading a method's Overview or Factsheet before opening its panel.
- Seeing how far the documentation has come, and what is still missing.

## What Panel Documentation Does Not Do
The Panel Documentation page does not search inside the text of the wikis: the search box matches the names of panels and wikis, and a question about their content is for Ask Pollis. Wikis cannot be edited here, and the page does not open panels themselves.
