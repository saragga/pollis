# Security

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, report them privately using GitHub's
[private vulnerability reporting](https://docs.github.com/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
on this repository, under **Security → Report a vulnerability**.

Please include as much of the following as you can, so the issue can be reproduced:

- the type of issue, and the affected source file(s);
- the Pollis version, and your operating system and version;
- step-by-step instructions to reproduce it;
- proof-of-concept or exploit code, if you have it;
- what an attacker could achieve by exploiting it.

Pollis is maintained by one person, so please allow a reasonable period for a fix before any public
disclosure.

## Upstream vulnerabilities

Pollis is derived from [Code - OSS](https://github.com/microsoft/vscode). If the vulnerability is in
inherited upstream code rather than in Pollis-specific code, please also report it to Microsoft via
[https://aka.ms/SECURITY.md](https://aka.ms/SECURITY.md), since the fix will need to happen there.
